# Class Notes

## Registrar é preciso!!!

Em algum momento já passou pela cabeça aquela sensação de que você estudou muito, conhece bastante coisa, mas não tem nada concreto para mostrar? Para isto, estão aqui as Notas de Aula. 

É simples: Tudo o que for importante dos seus estudos, vá organizando e atualizado por aqui. Crie pastas para disciplinas ou assuntos ou linguagens, mas registre e organize de forma que consiga encontrar de forma intuitiva.

Às vezes só queremos lembrar como foi que solucionamos um problema enquanto estudávamos pra resolver aquele desafio de código. Não importa a linguagem, não importa o problema, ele pode ser parte da solução de algo maior no futuro, ou nos inspirar a resolver outros problemas.
