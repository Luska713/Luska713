# Challenges

## Desafios de Código

Aqui estão dispostos alguns desafios de código escritos em diversos formatos. Alguns códigos são matematicamente mais complexos, outros são desafios mais simples e de fácil compreensão.

Os arquivos em formato de Notebook Python se encontram com documentação mais robusta e elaborada, os demais - até pelas limitações de seus formatos - podem se apresentar de forma mais direta.

Não se engane pelo tamanho do código, às vezes pequenos arquivos trazem consigo uma bagagem imensa, com conteúdos que podem se tornar recursos bastante úteis para ajudar a solucionar problemas semelhantes. Normalmente, soluções que utilizam artifícios matemáticos podem se apresentar de forma mais elegante e  apresentam maior eficiência, pois utilizam menos recursos - memória e processamento - e requerem menos linhas de código.

Alguns conteúdos se encontram com documentação em pt-BR, facilitando o entendimento para brasileiros. Outros se encontram em inglês, estes geralmente possuem conteúdo de mais fácil assimilação mesmo para não falantes da língua inglesa.
