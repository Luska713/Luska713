# Colab Notes

## Sobre o Google Colab

O **Google Colab** permite escrever e executar código em **Python** diretamente pelo navegador.

O Google Colab, entre suas vantagens, não precisa de configuração, utiliza máquinas remotas potentes, permite a colaboração em tempo real e salva tudo automaticamente no Drive, possuindo também conexão direta com o GitHub.

O ambiente do Google Colab é baseado no Jupyter Notebook, organizando o trabalho em células.

### As células de texto

Células de texto utilizam a linguagem Markdown, como a utilizada neste README.md, permtindo a documentação de forma clara e ampla.

### As células de código

Nestas células você escreve e roda os seus scripts em Python, elas mostram a saída em uma área de visualização que permite tanto texto quanto imagem, ou seja, também é possível gerar gráficos e ler e exibir tabelas.

**OBS.**: Como mostrado em alguns dos arquivos aqui presente, os recursos do Google Colab permitem que a linguagem de programação não se resuma apenas a python, sendo possível por meio de artifícios codar também em linguagens como C e C++ um mesmo arquivo de Jupyter Notebook.

### Outros recursos

É possível montar o seu Google Drive no Google Colab, garantindo que arquivos criados possam ser salvos, já que os arquivos gerados em um ambiente temporário são apagados ao final da sessão de uso da máquina remota.

É possível navegar entre arquivos da máquina remota, fazer download e upload de arquivos e executar comandos diretamente no terminal, mas apenas os resultados gerados no arquivo *ipynb* permanecem salvos.

Algumas bibliotecas como Pandas, NumPy, e TensorFlow já vem pré-instaladas. É possível instalar outras bibliotecas, seja para automação, Web Scraping ou qualquer outro propósito.

## Sobre esta pasta

Aqui estão depositadas as notas de projetos e demais trabalhos realizados dentro do Google Colab. Dentro desta pasta, você encontra arquivos com dicas de uso do Colab, como construir códigos e outras linguagens além de Python dentro do colab, truques úteis, exemplos de uso da ferramenta, entre outros.

Arquivos salvos aqui não sincronizam com as pastas no Google Drive, portanto, o conteúdo dos arquivos editados aqui pode ser diferente dos constantes lá. Dê preferência a sempre salvar os arquivos e os editar a partir do GitHub, afinal, aqui é o seu currículo e cartão de visitas para o mundo.
